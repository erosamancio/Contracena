# Contracena

Cenas de improviso para jogar a dois. Vocês sorteiam uma cena, cada um lê o próprio papel em segredo e atuam como se fosse de verdade.

Jogue em https://erosamancio.github.io/contracena/

## Instalar no celular
- Android: abra o link no Chrome e toque em "Instalar app" (ou no menu ⋮, "Adicionar à tela inicial").
- iPhone: abra no Safari, toque em Compartilhar e depois em "Adicionar à Tela de Início".

Depois de aberto uma vez, funciona sem internet. O histórico, as notas e as favoritas ficam só no celular.

## Editar as cenas
As cenas ficam em `cenas.js`. Cada uma tem categoria, título, lugar, situação, os papéis de Ela e Ele (quem é, o que quer, segredo) e uma reviravolta opcional. Ao mudar arquivos, aumente `VERSAO` em `sw.js` para os celulares baixarem a versão nova.
